# Motion for Mac

This repository only carries release downloads and the auto-update feed for Motion.
The app itself, and the current download, live at https://motionstudio.live.

Each release includes:

- `Motion-<version>-arm64.dmg` — the installer
- `Motion.dmg` — the same installer under a fixed name, so https://motionstudio.live/download always points at the newest version
- `Motion-<version>-arm64.zip` and `latest-mac.yml` — used by the app to update itself

Requires macOS 13 or later on Apple silicon.
